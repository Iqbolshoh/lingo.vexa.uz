🛡️ 29-Bosqich: Guruh Xabarlarini Filtrlash & Spamni To‘xtatish

Bot Guruh Suhbatlariga Jim Turishi va Faqat Shaxsiyda Ishlashi Sozlandi

Foydalanuvchilar va dasturchilar guruhda suhbatlashganda botning qayta-qayta «Assalomu alaykum...» salomlashuvini yuborishi butunlay to‘xtatildi:

👥 GURUH & KANALLAR 🔇 JIM TURISH
if ($chatType !== 'private') {
  return; // Guruhda jim turadi
}
if (!empty($from['is_bot'])) {
  return; // Botlar siklini to‘xtatadi
}
Dasturchilar guruhidagi gap-so‘zlar, boshqa botlarning xabarlari yoki xizmat ma’lumotlari bot tomonidan e’tiborsiz qoldiriladi. Guruhga faqat rasmiy hodisalar yo‘naltiriladi.
👤 SHAXSIY CHAT (PRIVATE) ⚡ 100% FAOL
if ($chatType === 'private') {
  send_welcome_menu();
  handle_user_quiz();
  send_daily_word();
}
Talabalar botga shaxsiy xabar yozganda bot barcha 8 ta menyu buyruqlarini, testlarni, kunlik so‘z va hisob ma’lumotlarini to‘liq xizmat sifatida taqdim etadi.
